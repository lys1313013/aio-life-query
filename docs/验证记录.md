# 查询服务验证记录

文档核对日期：2026-10-18。下列“当前验证入口”按源码整理，表示测试的用途和边界；后面的日期记录保留当时结果。此次仅更新文档，未重新运行 Java / Python 业务测试、容器集成、Codex 客户端或镜像发布。

当前能力为六个数据集、配置覆盖 111 个物理字段、最长 366 天、REST / GraphQL HTTP / MCP 三个入口及时迹分类关系。时迹版本 `time-record-v3`，其余五个数据集 v2；完整契约见 [README](../README.md)。

## 当前验证入口

所有命令在本仓库根目录执行，需要 JDK 21；涉及容器时需要可用的 Docker，完整授权链还需要配套 `aio-life-server` 源码。

| 入口 | 覆盖与前提 |
|---|---|
| `mvn test` | 编译器、结果校验、授权客户端、请求边界、GraphQL 路由、MCP 兼容、审计及分类关系；未设置测试 Redis 时跳过 Redis 集成测试 |
| `AIO_QUERY_TEST_REDIS_PORT=<port> mvn -B -ntp verify -DfailIfNoTests=true` | 完整网关测试及打包；端口指向 `127.0.0.1` 的隔离无密码 Redis，包含票据重放、版本、并发释放 |
| `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py'` | 元数据文件权限、原子替换、失败恢复、字段 GRANT 一致性、用户及逻辑删除行权限、分类关系无独立根入口 |
| `bash scripts/build_connector.sh` | 校验固定归档和补丁指纹并打包 Connector；脚本跳过上游测试 |
| `bash scripts/test_e2e.sh` | 真实 AIO Life 授权 → 网关 REST / MCP → Hasura → Connector → MySQL；先构建 Connector，脚本打包网关并运行配套后端的指定测试 |
| `mvn package -DskipTests` 后运行 `python3 scripts/test_category_relationship.py` | 隔离分类关系查询链；先构建 Connector，授权端为本地桩，不代表真实 AIO Life 认证已验证 |
| `bash scripts/smoke_image.sh <gateway-image>` | 镜像启动、REST / MCP 认证及故障拒绝、运行身份和审计写权限；不覆盖完整业务链或 GraphQL HTTP 路由 |

完整隔离脚本默认占用 45680 / 45682 / 45683，支持通过 `AIO_QUERY_TEST_GATEWAY_PORT` / `AIO_QUERY_TEST_HASURA_PORT` / `AIO_QUERY_TEST_CONNECTOR_PORT` 改为其他空闲端口；MySQL、Redis 使用动态端口。`AIO_LIFE_SOURCE` 默认 `../aio-life-server`。日志在 `.cache/e2e/`、两仓库的 `target/surefire-reports/` 和后端 `target/query-e2e/`；退出时清理所创建的容器与 Connector 进程。

分类专项脚本使用动态端口及 `tests/category-fixture.sql`，日志和请求响应在 `.cache/category-e2e-*/`。源码断言包括公共分类名称覆盖、同名匹配、大整数 ID 字符串、嵌套别名、空关系、聚合、跨用户和逻辑删除隔离及只读账号拒绝更新。当前 MySQL 版本要求见 [分类关系说明](../README.md#按分类名称查询时迹)。
